# EPIC-008 — Groups & Communities

## Status: `blocked` (needs EPIC-002)
## Priority: P2 (Sprint 3)

## Goal
Users can form and join groups (open/closed/thematic/local/corporate),
each with a collective MHS score and group challenges.

## Scope
- Group types: Open, Closed, Thematic, Local, Corporate
- Group feed with active member count, collective MHS metrics
- Group challenges (e.g., "May Green Month — plant 100 trees")
- Collective MHS aggregation
- Group-level badge earning
- Group governance (admin roles, join requests, moderation)

## Tasks
- TASK-023: Group system backend
- TASK-024: Collective MHS + group challenges
- TASK-032: Group management UI (frontend)

## Definition of Done
- [ ] User can create/join/leave a group
- [ ] Collective MHS updates when a member's score changes
- [ ] Group challenge tracks progress toward target
- [ ] Group admin can approve/reject join requests (closed groups)
